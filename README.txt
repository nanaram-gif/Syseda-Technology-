INSTALL:
1. Buy a web hosting plan that supports WordPress and connect syseda.co.in to it.
2. Install WordPress using your hosting dashboard.
3. In WordPress Admin, go to Appearance > Themes > Add New Theme > Upload Theme.
4. Upload syseda-technology-theme.zip and click Install, then Activate.
5. Go to Settings > General and set the site title to SYSEDA Technology.
6. Create a page titled “Get a Quote” with slug “get-a-quote”.
7. Install a reputable form plugin (for example, Contact Form 7 or WPForms). Build a form with Name, Company, Phone, Email, Service Required, Project Details, and consent. Set notifications to info@syseda.co.in.
8. Go to Settings > Reading and set the homepage to “A static page” with a new page called “Home” if the theme's front page does not automatically display.
9. Set up SSL/HTTPS, backups, spam protection and privacy policy before advertising.
10. Test the quote form from a mobile phone and confirm the email arrives before using the URL in Meta Ads.

IMPORTANT:
- This theme does not itself store or email form submissions. Use a form plugin and test its email delivery.
- The quote page URL will be https://syseda.co.in/get-a-quote/ after you publish the page with that slug.
- If your hosting provider offers managed WordPress, that is generally the easiest route for a first website.
